# Ficha de lactancia · Lic. Cecilia Quevedo

Formulario para familias (`index.html`) y panel privado (`panel.html`). Las respuestas se guardan en Google (ver `apps-script/Codigo.gs`), no en este repositorio.

## Fotos para evaluación de motricidad orofacial

`fotos.html` guía al paciente con dibujos para sacar 14 fotos estandarizadas y las sube al mismo Apps Script (quedan como una fila "📷 Fotos MO · Nombre" y una carpeta en Drive). Link por paciente: `fotos.html?n=Nombre%20Apellido`. Los dibujos (`fotos-dibujos.js`) se generan desde la guía en PDF.
